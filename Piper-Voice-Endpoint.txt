

Heres my example of how I have it! (used opencode to set it up and have no actual setup script for this yet!

# Piper (local text-to-speech)
PIPER_PATH=/home/jay/Documents/Apps/ai-voice-chat/piper-venv/bin/piper
PIPER_VOICE=/home/jay/Documents/Apps/ai-voice-chat/voices/en_GB-alba-medium.onnx



PIPER_BIN="${PIPER_PATH:-venv/bin/piper}"
PIPER_VOICE="${PIPER_VOICE:-models/en_GB-alba-medium.onnx}"



# To setup piper run (this only installs missing pip modules required for openai compatability not actual full piper or its voices)!

# Setup the piper server and get a voice
./initial-piper-setup.sh

# Get the pip configured!
./piper-setup.sh

# To Use
./piper-server.sh 


# Stand alone mode
./piper-start.sh

# Then visit http://localhost:5000/

# Test Command for stand alone mode!
curl -X POST http://127.0.0.1:5000/v1/audio/speech \
    -H "Content-Type: application/json" \
    -d '{"model":"piper","voice":"en_GB-alba-medium","input":"Hello Jay, this is your local Piper voice.","response_format":"wav"}' \
    -o /tmp/piper-test.wav && paplay /tmp/piper-test.wav
    


~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

You will need to setup piper in a venv and then you can use the piper scripts to make your own endpoint!
